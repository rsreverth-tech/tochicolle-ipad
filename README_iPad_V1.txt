トチコレ！ハンター iPad BRANCH V1（V77ベース）

■ 推奨端末
- iPad 第10世代 / 横向き
- Safari
- ゲーム論理画面は16:9固定

■ 初回セットアップ
1. HTTPSでこのフォルダを公開してSafariで開く
2. カメラ許可をON
3. 「共有」→「ホーム画面に追加」
4. 一度起動してCACHE READYを確認
5. 機内モードにして再起動し、タイトル→カメラ→キャリブレーション→1ゲーム完走まで確認

※ file:// でindex.htmlを直接開く方法では、カメラ/PWA/Service Workerが正常動作しない場合があります。

■ カメラ
- 初期値：iPad背面カメラ（environment）
- 設定画面の「使用カメラ」でSafariが認識したUSB/UVCカメラを選択可能
- カメラ変更時は保存済みキャリブレーションを解除し、再登録を要求
- DJI Osmo Action 5 ProのiPad Safari認識は実機で要確認

■ V77からの主な変更
- 16:9ゲームサーフェス固定
- iPadタッチ操作対応を強化
- iPad背面カメラ優先
- カメラデバイス選択UI追加
- PWA manifest / Service Worker / 全ローカルアセットキャッシュ
- Google Fonts外部読込を削除しオフライン化
- iPad向けカメラ設定文言へ変更
- カメラ起動成功後にカウントダウン開始

■ PC版について
このフォルダはiPad専用分岐です。PC版の保存基準には上書きしないでください。
