トチコレ！ハンター iPad v1

■ 変更内容
・iPad Safari向け viewport / safe-area 対応
・100dvh対応（Safariのアドレスバー表示変化対策）
・タッチ操作の誤選択、長押しメニュー、ダブルタップ系干渉を抑制
・タッチ端末ではボタンを押しやすいサイズへ調整
・4点画角登録ポイントをタッチしやすく調整
・縦向き時は「iPadは横向きで使用してください」を表示
・元v77のキャラクター、背景、検出ロジック、BGM/SE生成、ゲーム内容は維持

■ 重要：カメラモード
iPad/iPhoneのSafariでは、カメラ(getUserMedia)は原則として HTTPS または localhost の安全なコンテキストが必要です。
ZIPをiPadの「ファイル」から直接開く file:// 形式では、ゲーム画面が開いてもカメラが利用できない場合があります。
カメラモードを使う場合は、HTTPSで公開したURLをSafariから開いてください。

■ 起動
1. ZIPを展開
2. テストモードだけなら index.html を開く
3. 実際のカメラモードはHTTPS上へ配置してSafariで開く
4. iPadを横向きにする
5. 「カメラモード」→カメラ許可→画角登録→5cm球キャリブレーション
