とちコレ！ v61 — 薄ピンクボール専用検出版

■ ボール検出
・従来の広い「ピンク/赤ピンク」判定を廃止
・薄ピンク専用の固定カラープロファイルに変更
・HSV（色相/彩度/明度）＋RGB比率を併用
・白、肌色、赤、オレンジ、紫、暗いピンクを除外する方向に厳格化
・孤立ノイズ除去を追加
・連結領域の面積、縦横比、塗りつぶし率でボール形状を判定
・投球時のモーションブラーを考慮し、完全な真円には限定しない
・最大4球の同時検出/追跡は維持

■ ゲーム側
・V60のキャラクター拡大を維持
・4点キャリブレーション、BGM/SE、SR/SSR/UR、ボス等を維持

※ 照明条件で薄ピンクの見え方は変わるため、実機テスト後に色域をさらに詰める前提の専用版です。
