トチコレ！ハンター iPad V2

V1からの主な変更
- iPad内蔵カメラを「背面カメラ」「前面カメラ」の2ボタンで明示的に切替可能に変更。
- 背面は facingMode=environment、前面は facingMode=user を優先して要求。
- USB/UVCカメラは別のプルダウンから選択可能。
- カメラ変更時は誤判定防止のためキャリブレーションを解除。
- PWAキャッシュ名をV2へ更新。

ホーム画面アプリ化
SafariでHTTPS配信URLを開き、共有 → ホーム画面に追加 → Webアプリとして開く をオン → 追加。
初回キャッシュ後、機内モードで「起動→カメラ→キャリブレーション→1ゲーム完走」を必ず実機確認すること。
